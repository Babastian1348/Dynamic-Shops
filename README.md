# Dynamic Shops

Well, this is my very first mod, I wanted to make something simple but useful for those who want an economy system in their Minecraft servers, this mod was AI-assisted, all the features, texts, translations, textures and code supervision was human-made, I just wanted to make something simple for my friends and wanted to share it here!

---

## Main Features

*   ** Added Shop blocks and Sell blocks, if you have OP or you are in creative mode, you can shift+right click to open the Config GUIs, where you can choose which item to sell/buy, its price, if it has stock/limit and choose a custom display name. Shop blocks and Sell blocks come in the 16 different dye colors and also are naturally unbreakable. Stock and Limit period of time can be changed in the config
*   ** Added Money component which can be seen with the /money balance <player> command, money can go from 0 to 999,999,999, if you die, you lose half of your current money
*   ** Added Tasks, ways the player can earn money by doing certain activities: Killing passive/hostile mobs, Mining ores, logs and common blocks, Exploring, Completing achievements, Smelting items, Trading with Villagers, Exploring, Fishing and placing blocks, the progress of a certain task can be seen with the /task progress <player> <task>. Tasks amount of reward can be changed in the config.
*   ** Added ATM block, this block is used to store money, the money stored in the ATM is not lost when a player dies, in the ATM players can deposit, withdraw and physical withdraw their money, also if a certain number of days pass in the game, any money stored inside an ATM has a dynamic interest applied, this values can be changed in the config
*   ** Added Currency items, useful to make payments with other players or just to show off

*   ** Vending Machines: blocks that can sell multiple groups of Items just in one area
*   ** Voucher: Utility item for selling more than just physical items
*   ** Shop colaborators: An option to make players colaborate and get a percentage of the store's profits
*   ** Improved money system: Negative money, decimals, taxes, etc.
